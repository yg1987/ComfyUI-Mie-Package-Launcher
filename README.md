# ComfyUI 启动器（自用版）

本仓库基于 [ComfyUI-Mie-Package-Launcher 原项目](https://github.com/MieMieeeee/ComfyUI-Mie-Package-Launcher)维护。

除以下两个自用菜单外，其余功能均同步自原项目：

## 自用-插件管理

用于管理自用 GitHub 插件的版本与依赖：

- 查看插件版本和当前状态
- 检查并更新插件
- 安装、卸载、启用或禁用插件
- 更新前检查依赖变化，避免破坏现有环境

## 自用-软链接

用于管理自用目录软链接：

- 查看软链接配置和当前状态
- 创建或移除软链接
- 批量检查软链接
- 发现异常时进行安全修复
